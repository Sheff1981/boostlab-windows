# BOOSTLAB Windows

Future Windows client for BOOSTLAB.

The Android client is the first implementation target. This repository is reserved now so the protocol, configuration model and branding can remain consistent when the Windows client starts.

## Planned responsibilities

- Application/process selection.
- Tunnel lifecycle.
- Gateway selection.
- Ping / jitter / packet-loss display.
- Diagnostics and safe fallback when a gateway is unavailable.

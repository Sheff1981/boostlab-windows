# BOOSTLAB Windows

## Status: paused

The user-facing BOOSTLAB client is currently **Android-only**.

This repository is kept so the existing modern C# / .NET 10 / WinUI 3 work is not lost, but Windows client feature development is paused.

Windows may still be used as a temporary local development machine for testing the Android client against the BOOSTLAB gateway.

Do not add new Windows client functionality until the Android path is proven end-to-end.
